1) PGP es un criptosistema híbrido que combina técnicas de criptografía simétrica y criptografía asimétrica.
¿qué aprovecha PGP de cada una de estas técnicas? Si quiere puede utilizar IA, si es así cite la fuente y haga su propia crítica de lo que dice la IA.

Aprovecha lo mejor de ambos tipos de criptografía en un modelo híbrido: De la criptografía simétrica, PGP aprovecha su velocidad y eficiencia para cifrar el contenido real del mensaje. Utiliza un algoritmo simétrico (por ejemplo, AES o IDEA) para generar una clave de sesión aleatoria, con la que cifra el texto o archivo completo. Este enfoque reduce el costo computacional, ya que los algoritmos simétricos son mucho más rápidos para grandes volúmenes de datos. De la criptografía asimétrica, PGP aprovecha la seguridad del intercambio de claves y la autenticidad. La clave de sesión simétrica (usada para cifrar el mensaje) se cifra a su vez con la clave pública del destinatario. Solo el receptor, con su clave privada, puede descifrar esa clave de sesión y, por lo tanto, acceder al contenido. Además, PGP usa la clave privada del emisor para firmar digitalmente el mensaje, garantizando integridad y autenticidad.

2) ¿Cuál es la diferencia entre un sistema de archivos y una partición de disco?

Una particion es una division logica del espacio fisico de un disco (HDD o SSD), permite separar el almacenamiento en secciones independientes que el sistema operativo puede manejar por separado; cada partición cuenta con un filesystem diferente. Mientras que un sistema de archivos es una estructura lógica que organiza los datos dentro de una partición: como se guardan los archivos, como se accede a ellos, como se administran los permisos, etc.

5) Defina Encoding y Criptografía. Cual es la diferencia entre estas dos?

Encoding: La codificación de caracteres es el método que permite convertir un carácter de un lenguaje natural (como el de un alfabeto osilabario) en un símbolo de otro sistema de representación, aplicando reglas de codificación. Se trata de diferentes formas de representar un mismo contenido.
Criptografia: Consiste en el estudio de técnicas que posibiliten transformar un mensaje legible en otro que no lo es. Sólo el emisor y el destinatario saben como devolverlo a su forma original, haciendo que cualquier otra persona que vea el mensaje cifrado no pueda entenderlo.
La diferencia radica en su objetivo final, la codificacion permite transformar los datos en otro formato usando un esquema disponible públicamente y puede ser fácilmente retransformado mientras que la criptografia sirve para mantener la confidencialidad de los datos.

6) Describa brevemente qué entiende por Imaging (imagen forense) y cómo lo realizaría.

un "imaging" o la creación de una imagen forense se refiere al proceso de hacer una copia exacta, bit a bit, de un dispositivo de almacenamiento completo (como un disco duro, una memoria USB, un SSD, etc.).
Fase 1: Preparación
Se aísla y asegura el dispositivo para evitar alteraciones.
Si está encendido, se extrae la memoria RAM y luego se apaga de forma controlada.
Si está apagado, se extrae el disco y se conecta a la estación forense con un bloqueador de escritura.
Se prepara el equipo con software forense (FTK Imager, Guymager, dd, etc.) y se documentan los datos del dispositivo (modelo, número de serie, estado físico).
Fase 2: Adquisición
Se crea una imagen forense del disco usando el bloqueador de escritura.
Se configuran fuente, destino y formato (E01 o RAW).
Se registran metadatos del caso.
Se calculan hashes (MD5/SHA-1) para garantizar la integridad de los datos.
Fase 3: Verificación y Documentación
Se verifica la integridad comparando los hashes del disco original y la imagen.
Luego se documenta todo (fechas, investigador, hashes, tamaño, errores) y se actualiza la cadena de custodia para mantener trazabilidad.

7) ¿Qué es la esteganografía? ¿Para qué se utiliza? De un ejemplo.

La esteganografía es la técnica de ocultar información dentro de otro objeto o medio portador, de manera que la existencia misma del mensaje secreto pase desapercibida. El objetivo es que un observador casual no tenga ninguna razón para sospechar siquiera que hay un mensaje secreto presente.
Se puede utilizar para la comunicación segura y discreta, control de integridad, campos militares y de inteligencia, etc.

Ejemplo: Marcas de Agua Digitales: Ocultar información de copyright o de propiedad dentro de una imagen, video o audio para proteger los derechos de autor. Esta marca es imperceptible para el usuario, pero puede ser detectada por el propietario para demostrar la autoría.
